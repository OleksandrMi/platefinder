# Поиск номеров (веб-версия)

Распознавание польских автомобильных номеров камерой телефона в реальном времени.
Работает в браузере на iPhone и Android, без установки из магазина.

- Подсветка номеров из своего списка (красный — искомые, зелёный — свои)
- Подсветка по кодам повятов (все коды Польши, включая служебные)
- Фото, видео (удерживать кнопку), сохранение точки GPS, журнал с экспортом CSV/KML
- Работает офлайн после первого запуска

## Как пользоваться на iPhone

1. Откройте ссылку на сайт в Safari.
2. «Поделиться» → «На экран „Домой“» — так приложение открывается без адресной строки
   и iPhone не очищает ваши данные.
3. Разрешите доступ к камере и геолокации.
4. «Список» → «Импорт» — загрузите свой `plates.txt` или вставьте номера текстом.

## Приватность

Список номеров, журнал, фото и видео хранятся только в браузере на вашем телефоне
и никуда не отправляются. Распознавание выполняется на устройстве (Tesseract.js).
